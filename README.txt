TOOLNEST FREE WEBSITE STARTER
=============================

FILES
- index.html: website content and tool panels
- style.css: colors, layout, mobile responsiveness
- script.js: photo editing, image conversion, resizing and percentage calculator
- README.txt: these instructions

PUBLISH FOR FREE WITH GITHUB PAGES
1. Extract this ZIP file on your computer.
2. Create/sign into a GitHub account at https://github.com/signup
3. Create a PUBLIC repository named YOURUSERNAME.github.io (replace YOURUSERNAME with your GitHub username).
4. In that repository, choose Add file > Upload files.
5. Upload index.html, style.css and script.js from this folder (you can also upload README.txt).
6. Commit the files.
7. Open repository Settings > Pages.
8. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
9. Wait for deployment and open https://YOURUSERNAME.github.io/

IMPORTANT
- This starter website does not cost anything to download or host on GitHub Pages within its plan limits.
- Photo editing, image conversion, resizing and percentage calculations work in the visitor's browser.
- Translation, AI enhancement, background removal, PDF creation, analytics and advertising are NOT included yet.
- Do not add API keys or passwords to public JavaScript files.
- Before applying for ads, add genuine useful content, contact/about/privacy pages, and check current ad network policies.
- A free website URL is not a custom .com domain.
